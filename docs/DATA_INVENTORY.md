## 2️⃣ Neo4j 그래프 DB

### 기본 정보

- **호스팅:** (Neo4j Aura, 로컬, 자체 서버 등)
- **데이터 규모:**
  - 노드 수: ___개
  - 엣지(관계) 수: ___개

### 노드 타입 (Labels)
```
(:NodeType1) - 설명, 예상 개수
(:NodeType2) - 설명, 예상 개수
...

예시:
(:MicroSkill) - 12개 마이크로스킬, 12개
(:AchievementStandard) - 성취기준, ~50개
(:Vocabulary) - 어휘 노드, ~3000개
```

### 관계 타입 (Relationships)
```
[:RELATIONSHIP_TYPE] - 설명
...

예시:
[:REQUIRES] - 선수 지식 관계 (A를 알아야 B를 풀 수 있음)
[:BELONGS_TO] - 소속 관계 (문제 → 스킬)
[:SYNONYM] - 동의어 관계
```

### 주요 Cypher 쿼리 예시
```cypher
// 예: 특정 스킬의 선수 지식 조회
MATCH (s:MicroSkill {code: 'A1'})-[:REQUIRES*1..3]->(prereq)
RETURN prereq
```
